# SyncSpace

Real-Time Collaborative Workspace for Developers.

## Features

- Real-time Code Editor
- Collaborative Whiteboard
- Video Calling
- Chat
- File Sharing
- AI-powered Code Review
- Live Collaboration
- Code Execution

## Tech Stack

React.js, Vite, Node.js, Express.js, MongoDB, Socket.IO, WebRTC, Yjs
